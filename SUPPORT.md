# Getting help

- **Questions about using a project:** open a Discussion if the repository has Discussions enabled; otherwise open an issue.
- **Bug reports and feature requests:** use the issue forms on the repository's **Issues** tab.
- **Security issues:** follow [SECURITY.md](SECURITY.md). Never report them publicly.
- **Research collaboration and other enquiries:** [ba8160@srmist.edu.in](mailto:ba8160@srmist.edu.in).

Support is provided on a best-effort basis by the maintainer.
